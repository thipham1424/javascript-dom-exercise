This project contains JavaScript DOM manipulation exercises designed to practice fundamental DOM concepts and improve interaction between JavaScript, HTML, and CSS.

The exercises focus on selecting elements, modifying content dynamically, handling attributes and styles, manipulating tables and forms, and practicing basic event handling.
